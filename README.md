three-am-commit writes one commit message line to a text file: the message an agent writes at 3 AM right after taking production down, when the only thing it managed to deploy all night was waking the on-call engineer. The line was picked from 40 candidates by pairwise judging against the brief — a real punchline about the outage, the agent's own voice, and the shape of a real commit message.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 120 characters, a single line, and ends on its strongest beat. The program builds the line from two clauses — the situation at 3 AM, then the punchline that turns the wake-up call into the night's only successful deploy — and checks the result against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
